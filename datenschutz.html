Datenschutzerklärung – Ambient Video Automation

Wer die Anwendung nutzt

Ambient Video Automation ist ein privates Werkzeug. Es wird ausschließlich vom Betreiber für seinen eigenen YouTube-Kanal verwendet und steht keinen anderen Nutzern zur Verfügung.

Auf welche Google-Daten zugegriffen wird

  • YouTube-Upload (youtube.upload): Hochladen von Videos auf den eigenen Kanal.
  • YouTube-Lesezugriff (youtube.readonly): Abrufen von Kanal- und Videostatistiken (Abonnenten, Aufrufe, Likes) für eine Übersicht.

Speicherung und Weitergabe

Das Zugangstoken und der Statistikverlauf werden nur lokal auf dem Rechner des Betreibers gespeichert. Es werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt, und es werden keine Daten an eigene Server übertragen.

Die Nutzung von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Zugriff widerrufen

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Es gelten außerdem die Datenschutzerklärung von Google und die Nutzungsbedingungen von YouTube.
